# Архитектурные требования

## Общее описание

Проект представляет собой персональный трекер привычек с визуализацией прогресса и статистикой.  
Реализован в виде monorepo с двумя пакетами:

1. **`packages/ui`** — библиотека общих UI-компонентов
2. **`packages/app`** — основное React-приложение

Оба проекта написаны на **TypeScript**, используют ES-модули (`"type": "module"`).

## 3. Компоненты библиотеки `packages/ui`

| Компонент     | Назначение                                                                 |
|---------------|----------------------------------------------------------------------------|
| `Button`      | Универсальная кнопка (варианты: primary, secondary, danger)                |
| `Card`        | Карточка-контейнер для группировки контента                                |
| `ProgressBar` | Горизонтальный индикатор прогресса (процент выполнения привычки)           |
| `HabitCard`   | Карточка привычки: название, прогресс, кнопка отметки выполнения           |
| `BarChart`    | Горизонтальная столбчатая диаграмма для сравнения значений                 |

Все компоненты экспортируются через `packages/ui/src/index.ts`.

## 4. Структура роутинга (`packages/app`)

| Путь            | Страница            | Описание                                      | Параметры / Защита |
|-----------------|---------------------|-----------------------------------------------|--------------------|
| `/`             | `HomePage`          | Дашборд: привычки на сегодня + общий прогресс | —                  |
| `/habits`       | `HabitsPage`        | Список всех привычек                          | —                  |
| `/habits/:id`   | `HabitDetailPage`   | Детальная информация о привычке + история     | `id` (string)      |
| `/statistics`   | `StatisticsPage`    | Статистика и визуализация прогресса           | —                  |
| `*`             | `NotFoundPage`      | Страница 404                                  | —                  |

Защищённые маршруты в текущей версии не предусмотрены (приложение однопользовательское, данные хранятся локально).

Вложенность маршрутов: отсутствует (плоская структура).

## 5. Использование библиотеки основным приложением

Основное приложение (`packages/app`) зависит от `@habit-tracker/ui` через workspace.

Пример использования:

```tsx
import { Button, Card, ProgressBar, HabitCard } from '@habit-tracker/ui'

// На главной странице отображается ProgressBar и HabitCard
```

Компоненты библиотеки используются минимум на `HomePage` и `HabitsPage`.

---

## 6. Дополнительные архитектурные решения

- Состояние привычек хранится в `localStorage` и синхронизируется через React Context (`HabitsProvider`).
- Стилизация: CSS Modules + небольшие глобальные стили.
- Сборка: Vite (library mode для `ui`, application mode для `app`).
- Тесты: Jest + Testing Library (обязательное покрытие ≥ 70% хотя бы одного компонента библиотеки).
